# 📝 Todo Manager

Консольный менеджер задач на Python. Позволяет добавлять и удалять задачи, а все данные сохраняются в файл, поэтому после закрытия программы список не пропадает.

## Возможности
- Показать список задач
- Добавить новую задачу (пустые задачи не принимаются)
- Удалить задачу по номеру
- Автоматическое сохранение в файл `tasks.json`
- Защита от неверного ввода (буквы вместо номера, несуществующий номер)

## Как запустить
1. Установите [Python 3](https://www.python.org/downloads/)
2. Скачайте файл `main.py`
3. Откройте терминал в папке с файлом и выполните:

```
python main.py
```

## Пример работы
```
--- СПИСОК ЗАДАЧ ---
1. Показать задачи
2. Добавить задачу
3. Удалить задачу
4. Выход

Выберите пункт (1-4): 2

Введите новую задачу: Подготовить портфолио
Задача 'Подготовить портфолио' добавлена!

Выберите пункт (1-4): 1

Ваши задачи:
1. Подготовить портфолио
```

## Как это устроено
- `load_tasks()` читает задачи из файла при запуске
- `save_tasks()` записывает их в файл после каждого изменения
- `show_tasks()` выводит нумерованный список
- Данные хранятся в формате JSON
